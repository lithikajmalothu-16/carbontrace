How it works

  1. Read: Azure AI Document Intelligence extracts each value and records the page it came from.
  2. Check: rule-based checks catch unit errors, year-over-year anomalies, duplicates, missing data and hidden instructions. Code does all the math.
  3. Investigate: an AI agent (Azure OpenAI via Microsoft Foundry) uses tools to investigate each flag and explains it with evidence.
  4. Review: an analyst approves, corrects or rejects. The AI never approves anything.
  5. Audit: every step is logged: who, when, what, and why.
